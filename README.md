# Route 66 Burgers - site pixel-perfect baseado no Canva

Este projeto usa as telas exportadas do Canva como base visual. Assim, o resultado fica praticamente idêntico ao PDF/Canva.

## Como usar
Abra `index.html` no navegador.

## Como publicar no GitHub Pages
1. Envie a pasta `route66_burgers_canva_site` para o repositório.
2. No GitHub, vá em Settings > Pages.
3. Configure a publicação pela branch principal.

## Observação
As áreas clicáveis são transparentes, posicionadas sobre as telas PNG. Isso mantém o visual idêntico e permite navegação básica entre telas.
